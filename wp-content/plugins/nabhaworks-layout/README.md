# Nabhaworks Layout (plugin)
Layout dell'articolo singolo: testata blu, immagine grande, colonna "Correlati", colore per categoria.
Installazione: copiare questa cartella in wp-content/plugins/ del repository, commit + push, poi attivare il plugin da WordPress.
Per disattivarlo basta spegnerlo da Plugin: il sito torna al layout di Blocksy.
